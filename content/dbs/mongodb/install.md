## 安装MongoDB Community Edition

### 在Linux上安装

> > 说明：以下内容摘自mongodb.com中	
>
> ​	为了获得最佳安装体验，MongoDB 提供适用于常用 Linux 发行版的包。这些包是运行 MongoDB 的首选方式。以下指南详细介绍了在对应系统上的安装过程：
>
> - [在 Red Hat 上安装](https://www.mongodb.com/zh-cn/docs/manual/tutorial/install-mongodb-on-red-hat/#std-label-install-mdb-community-redhat-centos)
>
>   使用 `.rpm` 包在 Red Hat Enterprise 和相关 Linux 系统上安装 MongoDB Community Edition。
>
> - [在 Ubuntu 上安装](https://www.mongodb.com/zh-cn/docs/manual/tutorial/install-mongodb-on-ubuntu/#std-label-install-mdb-community-ubuntu)
>
>   使用 `.deb` 软件包在 Ubuntu Linux 系统上安装 MongoDB Community Edition。
>
> - [在 Debian 上安装](https://www.mongodb.com/zh-cn/docs/manual/tutorial/install-mongodb-on-debian/#std-label-install-mdb-community-debian)
>
>   使用 `.deb` 软件包在 Debian 系统上安装 MongoDB Community Edition。
>
> - [在 SUSE 上安装](https://www.mongodb.com/zh-cn/docs/manual/tutorial/install-mongodb-on-debian/#std-label-install-mdb-community-debian)
>
>   使用 `.rpm` 软件包在 SUSE Linux 系统上安装 MongoDB Community Edition。
>
> - [在 Amazon 上安装](https://www.mongodb.com/zh-cn/docs/manual/tutorial/install-mongodb-on-amazon/#std-label-install-mdb-community-amazon-linux)
>
>   使用 `.rpm` 软件包在 Amazon Linux AMI 系统上安装 MongoDB Community 版。
>
